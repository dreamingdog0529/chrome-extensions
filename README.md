# chrome-extensions

自作 Chrome 拡張機能をまとめたリポジトリです。拡張機能ごとにフォルダを分けています。

## 一覧

| フォルダ | 内容 |
|---|---|
| `github-date-format/` | GitHub の日時表示を `yyyy/MM/dd HH:mm` 形式に書き換える拡張機能 |
| `x-quick-block/` | X（Twitter）の各投稿に 🚫 ボタンを追加し、ワンクリックで投稿者をブロックする拡張機能 |

## 使い方

各フォルダの README を見てください。共通の流れ：

1. Chrome で `chrome://extensions/` を開く
2. 「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」から、使いたい拡張機能のフォルダを選ぶ
