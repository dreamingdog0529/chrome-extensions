# Twitter Blocker - 1-Click Quick Block

X（Twitter）の各投稿の右上に 🚫 ボタンを追加し、ワンクリックで投稿者をブロックできる Chrome 拡張機能です。

## 仕様

1. 各投稿の右上、「･･･」メニューの左に 🚫 ボタンが表示されます（タイムライン・検索・プロフィール・返信欄など、すべての投稿が対象）。ボタンの色はテーマ連動で、ダークテーマでは白、ライトテーマでは黒です
2. ボタンを押すと即ブロックします（確認画面なし）
3. ブロック直後、画面下に「取り消す」表示が **3秒間** 出ます。押せばブロックを解除して投稿を元に戻します
4. ブロックが成功すると、その人の投稿は画面からすべて消えます
5. 自分の投稿にはボタンは出ません。ブロックに失敗したときは投稿は消えず、エラーを表示します

## インストール方法（約2分）

1. このフォルダを PC に置きます（zip の場合は先に解凍してください）
2. Chrome で `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」を ON にします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダ（`manifest.json` があるフォルダ）を選びます
5. X（https://x.com）を開き直すと、各投稿にボタンが出ます

## 注意

- X の画面仕様が変わると、ボタンが出なくなる場合があります。そのときは調整が必要です
- ブロックは X の公式のブロックと同じものです。取り消し（3秒を過ぎた場合）は、相手のプロフィール等から通常の手順で解除できます
