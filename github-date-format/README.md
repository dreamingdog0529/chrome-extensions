# GitHub Date Format - yyyy/MM/dd HH:mm

GitHub の日時表示（「2 hours ago」のような相対表示）を、`yyyy/MM/dd HH:mm` 形式（例：`2026/11/23 01:18`）に書き換える Chrome 拡張機能です。

## 仕様

1. 対象は github.com のみです
2. 相対表示（`relative-time` / `time-ago`）と、英語の絶対表示（`local-time`、例：`Nov 23, 2026, 1:18 AM`）の両方を `yyyy/MM/dd HH:mm` に統一します
3. 時刻はお使いの PC のタイムゾーン（通常は日本時間）で表示します。秒は表示しません
4. 後から読み込まれる内容（ページ内遷移、追加読み込み、メニューなど）にも自動で適用されます
5. 元の要素と置き換える方式なので、GitHub 側の自動更新で相対表示に戻ることはありません

## インストール方法（約2分）

1. このフォルダを PC に置きます（zip の場合は先に解凍してください）
2. Chrome で `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」を ON にします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダ（`manifest.json` があるフォルダ）を選びます
5. GitHub（https://github.com）を開き直すと、日時が新しい形式で表示されます

## 注意

- GitHub の画面仕様が変わると、適用されなくなる場合があります。そのときは調整が必要です
- 日時のツールチップ（ホバーで出る詳細）は元のまま残ります
